## Example project you can inspect right now

**Question:** How did the unemployment rate and average hourly wage change in four fictional counties from 2024 to 2025?

The [economics project files](../examples/economics/) include a toy CSV, the question, a results note, a data dictionary, and a review checklist. The values are **not real observations** and make **no causal claim**.

The teaching workflow has real GitHub links: [original commit](https://github.com/ningzhanglab/Github-for-Beginners/commit/ef5dc6484fa1b9027c1e28eed92f9d2a7fccf6b4) → [task](https://github.com/ningzhanglab/Github-for-Beginners/issues/3) → [reviewed change](https://github.com/ningzhanglab/Github-for-Beginners/pull/4/files).

**Important:** Practice modifications on **your own practice repository** rather than pushing examples into this shared teaching repository.
