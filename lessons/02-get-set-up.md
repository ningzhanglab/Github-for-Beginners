# Lesson 2: Get set up

> **You'll learn:** how to make a GitHub account, install GitHub Desktop, and connect the two.
> **Time:** 10 minutes. **You need:** an email address and a Mac or Windows computer.

## Steps

### <img src="../assets/icons/account.svg" width="36" height="36" alt=""> Step 1: Create a free GitHub account

<img src="../assets/icons/place-web.svg" width="20" height="20" alt=""> **On GitHub.com**

**Do this:** go to [github.com/signup](https://github.com/signup), enter your email, choose a password and a username, and confirm your email address.

**You'll see:** your GitHub.com home page, with your username in the top-right corner.

> <img src="../assets/icons/warning.svg" width="20" height="20" alt=""> **Watch out:** Your username appears on everything you share. Pick one you're happy for coauthors to see.

### <img src="../assets/icons/install.svg" width="36" height="36" alt=""> Step 2: Install GitHub Desktop

<img src="../assets/icons/place-desktop.svg" width="20" height="20" alt=""> **In GitHub Desktop**

**Do this:** download the app from [desktop.github.com](https://desktop.github.com/) and open it.
- **Mac:** open the downloaded file and drag **GitHub Desktop** into **Applications**.
- **Windows:** run the downloaded installer; the app opens when it's done.

**You'll see:** a welcome screen.

> <img src="../assets/icons/warning.svg" width="20" height="20" alt=""> **Watch out:** You don't need to install "Git" separately or open a terminal. GitHub Desktop includes everything.

### <img src="../assets/icons/account.svg" width="36" height="36" alt=""> Step 3: Sign in to GitHub Desktop

<img src="../assets/icons/place-desktop.svg" width="20" height="20" alt=""> **In GitHub Desktop**

**Do this:** on the welcome screen, click **Sign in to GitHub.com**. Your browser opens; approve the request, then return to the app.

If you skipped the welcome screen, open the settings instead:
- **Mac:** **GitHub Desktop → Settings… → Accounts → Sign in**
- **Windows:** **File → Options… → Accounts → Sign in**

**You'll see:** your GitHub username listed under **Accounts**.

### <img src="../assets/icons/edit.svg" width="36" height="36" alt=""> Step 4: Choose a text editor (optional)

<img src="../assets/icons/place-desktop.svg" width="20" height="20" alt=""> **In GitHub Desktop**

**Do this:** in the same settings window, open **Integrations** and pick an **External Editor** if you have one, such as Visual Studio Code. If you don't, that's fine: you can always open files from the folder with TextEdit (Mac) or Notepad (Windows).

**You'll see:** later, the menu item **Repository → Open in** *your editor* opens your whole project in one click.

> <img src="../assets/icons/warning.svg" width="20" height="20" alt=""> **Watch out:** On a Mac, TextEdit sometimes saves as "rich text". Choose **Format → Make Plain Text** before editing `.md` files.
