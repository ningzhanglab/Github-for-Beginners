# One-page cheat sheet

Print this or keep it open. The icon colour tells you where: <img src="../assets/icons/place-folder.svg" width="20" height="20" alt=""> your folder, <img src="../assets/icons/place-desktop.svg" width="20" height="20" alt=""> GitHub Desktop, <img src="../assets/icons/place-web.svg" width="20" height="20" alt=""> GitHub.com.

## I want to…

| | I want to… | Click |
|---|---|---|
| <img src="../assets/icons/new-repo.svg" width="20" height="20" alt=""> | Start a new project | **File → New repository…** |
| <img src="../assets/icons/clone.svg" width="20" height="20" alt=""> | Get someone's project onto my computer | **File → Clone repository…** |
| <img src="../assets/icons/open-folder.svg" width="20" height="20" alt=""> | Find my project's folder | **Repository → Show in Finder / Show in Explorer** |
| <img src="../assets/icons/edit.svg" width="20" height="20" alt=""> | Edit files | **Repository → Open in** *your editor*, then save |
| <img src="../assets/icons/changes.svg" width="20" height="20" alt=""> | See what I changed | **Changes** tab |
| <img src="../assets/icons/commit.svg" width="20" height="20" alt=""> | Save a checkpoint | Type a Summary → **Commit to** *branch* |
| <img src="../assets/icons/publish.svg" width="20" height="20" alt=""> | Put a new project or branch online | **Publish repository** / **Publish branch** |
| <img src="../assets/icons/push.svg" width="20" height="20" alt=""> | Upload my checkpoints | **Push origin** |
| <img src="../assets/icons/fetch.svg" width="20" height="20" alt=""> | Check for online changes | **Fetch origin** |
| <img src="../assets/icons/pull.svg" width="20" height="20" alt=""> | Download online changes | **Pull origin** |
| <img src="../assets/icons/history.svg" width="20" height="20" alt=""> | See older versions | **History** tab |
| <img src="../assets/icons/branch.svg" width="20" height="20" alt=""> | Try something safely | **Current Branch → New branch** |
| <img src="../assets/icons/pull-request.svg" width="20" height="20" alt=""> | Ask for a review | **Preview Pull Request → Create pull request** |
| <img src="../assets/icons/review.svg" width="20" height="20" alt=""> | Read proposed changes | Pull request → **Files changed** |
| <img src="../assets/icons/merge.svg" width="20" height="20" alt=""> | Accept a pull request | **Merge pull request → Confirm merge** |
| <img src="../assets/icons/issue.svg" width="20" height="20" alt=""> | Write down a task | **Issues → New issue** |
| <img src="../assets/icons/undo.svg" width="20" height="20" alt=""> | Undo the commit I just made | **Undo** (below the commit box) |
| <img src="../assets/icons/revert.svg" width="20" height="20" alt=""> | Cancel a pushed commit | **History** → right-click → **Revert changes in commit** |
| <img src="../assets/icons/warning.svg" width="20" height="20" alt=""> | Throw away an uncommitted edit | **Changes** → right-click → **Discard changes…** |

## Three pairs people mix up

| | | |
|---|---|---|
| <img src="../assets/icons/commit.svg" width="20" height="20" alt=""> **Commit** saves on your computer | ≠ | <img src="../assets/icons/push.svg" width="20" height="20" alt=""> **Push** puts it online |
| <img src="../assets/icons/fetch.svg" width="20" height="20" alt=""> **Fetch** checks for news | ≠ | <img src="../assets/icons/pull.svg" width="20" height="20" alt=""> **Pull** brings it into your folder |
| <img src="../assets/icons/pull-request.svg" width="20" height="20" alt=""> **Pull request** proposes | ≠ | <img src="../assets/icons/merge.svg" width="20" height="20" alt=""> **Merge** accepts |

## The routes, in one line each

| | Route | Clicks |
|---|---|---|
| <img src="../assets/icons/push.svg" width="20" height="20" alt=""> | Save my work | edit → Changes → Commit → Push origin |
| <img src="../assets/icons/pull.svg" width="20" height="20" alt=""> | Get others' work | main → Fetch origin → Pull origin |
| <img src="../assets/icons/pull-request.svg" width="20" height="20" alt=""> | Propose a change | New branch → edit → Commit → Publish branch → Pull request → Merge → Pull main |
| <img src="../assets/icons/ai.svg" width="20" height="20" alt=""> | Use an AI safely | New branch → AI edits → review Changes → Commit → Pull request → you merge |
