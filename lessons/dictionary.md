# Plain-English dictionary

Every GitHub word used in this guide, in everyday language.

| | Word | Meaning | Lesson |
|---|---|---|---|
| <img src="../assets/icons/new-repo.svg" width="20" height="20" alt=""> | **Repository (repo)** | A project folder that remembers its history | [1](01-what-is-github.md) |
| <img src="../assets/icons/place-folder.svg" width="20" height="20" alt=""> | **Local** | On your computer | [1](01-what-is-github.md) |
| <img src="../assets/icons/place-web.svg" width="20" height="20" alt=""> | **Remote / origin** | The online copy on GitHub.com | [1](01-what-is-github.md) |
| <img src="../assets/icons/clone.svg" width="20" height="20" alt=""> | **Clone** | A connected copy of an online project on your computer | [6](06-work-with-other-people.md) |
| <img src="../assets/icons/changes.svg" width="20" height="20" alt=""> | **Changes** | What's different since your last checkpoint | [3](03-your-first-project.md) |
| <img src="../assets/icons/changes.svg" width="20" height="20" alt=""> | **Diff** | The view showing added (green) and removed (red) lines | [3](03-your-first-project.md) |
| <img src="../assets/icons/commit.svg" width="20" height="20" alt=""> | **Commit** | A named checkpoint, saved on your computer | [3](03-your-first-project.md) |
| <img src="../assets/icons/publish.svg" width="20" height="20" alt=""> | **Publish** | Put a new project or branch on GitHub.com for the first time | [3](03-your-first-project.md) |
| <img src="../assets/icons/push.svg" width="20" height="20" alt=""> | **Push** | Upload your checkpoints to GitHub.com | [4](04-save-and-sync.md) |
| <img src="../assets/icons/fetch.svg" width="20" height="20" alt=""> | **Fetch** | Check GitHub.com for anything new, without changing your files | [4](04-save-and-sync.md) |
| <img src="../assets/icons/pull.svg" width="20" height="20" alt=""> | **Pull** | Bring new checkpoints from GitHub.com into your folder | [4](04-save-and-sync.md) |
| <img src="../assets/icons/history.svg" width="20" height="20" alt=""> | **History** | The list of all checkpoints | [4](04-save-and-sync.md) |
| <img src="../assets/icons/branch.svg" width="20" height="20" alt=""> | **Branch** | A separate working version of the project | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/branch.svg" width="20" height="20" alt=""> | **main** | The usual name of the accepted, official branch | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/pull-request.svg" width="20" height="20" alt=""> | **Pull request (PR)** | A review page proposing to bring one branch's changes into another | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/pull-request.svg" width="20" height="20" alt=""> | **Base / compare** | In a pull request: the branch to change (base) and the branch with the proposal (compare) | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/pull-request.svg" width="20" height="20" alt=""> | **Draft pull request** | A pull request marked "not ready yet" | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/review.svg" width="20" height="20" alt=""> | **Review** | Reading a pull request and commenting, approving or asking for changes | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/review.svg" width="20" height="20" alt=""> | **Checks** | Automatic tests some projects run on pull requests; many beginner projects have none | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/merge.svg" width="20" height="20" alt=""> | **Merge** | Accept a pull request, so its changes join the other branch | [5](05-branches-and-pull-requests.md) |
| <img src="../assets/icons/issue.svg" width="20" height="20" alt=""> | **Issue** | A written task or question on GitHub.com | [6](06-work-with-other-people.md) |
| <img src="../assets/icons/people.svg" width="20" height="20" alt=""> | **Collaborator** | Someone the owner has allowed to upload to a project | [6](06-work-with-other-people.md) |
| <img src="../assets/icons/people.svg" width="20" height="20" alt=""> | **Fork** | Your own online copy of someone else's project, used when you can't upload to theirs | [6](06-work-with-other-people.md) |
| <img src="../assets/icons/ai.svg" width="20" height="20" alt=""> | **Agent / AI assistant** | AI software that may suggest, edit, or open pull requests, if allowed | [7](07-work-with-ai.md) |
| <img src="../assets/icons/undo.svg" width="20" height="20" alt=""> | **Undo** | Turn the commit you just made back into editable changes | [8](08-fix-mistakes.md) |
| <img src="../assets/icons/revert.svg" width="20" height="20" alt=""> | **Revert** | A new checkpoint that cancels an earlier one | [8](08-fix-mistakes.md) |
| <img src="../assets/icons/warning.svg" width="20" height="20" alt=""> | **Discard** | Throw away uncommitted edits (hard to undo) | [8](08-fix-mistakes.md) |
| <img src="../assets/icons/conflict.svg" width="20" height="20" alt=""> | **Conflict** | Two edits to the same lines that GitHub can't combine by itself | [8](08-fix-mistakes.md) |
| <img src="../assets/icons/branch.svg" width="20" height="20" alt=""> | **Worktree** | An optional extra folder for working on two branches at once. Beginners can skip it. | — |
