# All lessons

Eight short lessons, in order. Each one has a picture of its route and an icon for every step. Lessons 1 to 4 are all you need for a personal project; 5 to 8 add teamwork, AI and recovery.

## How to read the pictures

| | Icon colour | Where the step happens |
|---|---|---|
| <img src="../assets/icons/place-folder.svg" width="20" height="20" alt=""> | Amber | **Your project folder**: you edit files with your usual editor |
| <img src="../assets/icons/place-desktop.svg" width="20" height="20" alt=""> | Violet | **GitHub Desktop**: you review, commit and sync |
| <img src="../assets/icons/place-web.svg" width="20" height="20" alt=""> | Blue | **GitHub.com**: you and others review and accept changes |
| <img src="../assets/icons/ai.svg" width="20" height="20" alt=""> | Magenta | **An AI assistant** does this step; you check it afterwards |

A dashed circle on a route picture means someone else (a teammate or an AI) does that step.
