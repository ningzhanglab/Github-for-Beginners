# 05 · Need help?

If GitHub Desktop is confusing, first check **which project and branch you're viewing**. Many apparent "missing file" problems come from being on a different branch or from not pulling online changes.

## Two common situations

**I committed, but the website looks unchanged.** Did you click **Push origin**? Is the website showing the same branch you edited?

**My collaborator or cloud AI assistant merged a change, but my folder still looks old.** Switch to `main` in Desktop, click **Fetch origin**, then **Pull origin** when offered.

Do not click **Discard**, delete branches, or force-push just to make an error message disappear. Preserve important local work first.
