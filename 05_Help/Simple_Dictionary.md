# Plain-English Glossary and Official Links

This glossary is for operating **GitHub Desktop**. It does not teach the Git command line.

## Glossary

| Term | Beginner meaning | Why you care |
|---|---|---|
| Repository (repo) | A project folder with tracked history | The thing you clone and share |
| Clone | Make a connected copy on your computer | Start editing locally |
| Local | On your computer | Your editor and Desktop use these files |
| Remote / origin | The online connected copy on GitHub | Your shared project |
| Branch | An isolated version of a project | Keep experiments/agent work away from `main` |
| `main` | Common name for the accepted/default branch | Often the version others depend on |
| Changes / diff | Added, edited, or removed files/lines | Review before saving or merging |
| Commit | A labeled saved checkpoint on a branch | Track what changed |
| Push | Send commits from your computer to GitHub | Share locally completed work |
| Fetch | Check/download information about online changes | Find new branches/commits |
| Pull | Bring remote branch commits into the matching local branch | Update your local project |
| Pull request (PR) | A request to compare, discuss, and merge changes | Approve human or AI contributions |
| Merge | Accept one branch's change into another branch | Update the accepted version |
| Review | Examine PR changes; comment or approve on GitHub | Quality control |
| Issue | A named task or problem on GitHub | Brief an agent or human teammate |
| Conflict | Two changes cannot be automatically combined | Requires a deliberate choice |
| Revert | A new checkpoint that cancels a previous commit's changes | Safer shared undo |
| Worktree | A separate working folder linked to the same repository | Advanced way to work on two branches without changing the main folder |
| Agent | Software that may research, edit, and propose changes | Needs scope, permissions, and review |
| Check/status | Test or automation result shown on a PR | Useful evidence, not a guarantee of correctness |

## Who does what?

- **GitHub Desktop**: clone, choose branch, inspect local changes/history, commit, push, fetch, pull, view PR branch.
- **GitHub website**: issues, PR comments, reviews, approve/merge, access controls.
- **Editor**: change files, preview outputs, run or test projects.
- **AI agent**: may suggest edits, edit locally, or open remote PRs *if authorized*.
