First rule: don’t panic-click Discard, delete branches, or follow advice to “force push”. Find out where you are first: check Current Repository, Current Branch, then the Changes and History tabs.

What you seeUsually meansDo this
GitHub.com shows the old fileYou committed but didn’t push, or you’re viewing another branch.Push origin; check the branch selector on the website. See step 5
Your folder shows the old fileSomeone changed it online.Fetch origin, then Pull origin, on the right branch. See step 7
Files “disappeared” after switching branchesThat branch has a different version.Switch back with Current Branch. Check it before anything else. See step 8
An AI says it finished, but nothing changedIt worked on GitHub.com, or on a different folder.Ask for the pull request link or the folder path. See step 13
Desktop doesn’t know about your folderIt’s a ZIP download, not a clone.File → Clone repository… once, then work there.
Desktop lists conflicted files (a merge conflict)Two people changed the same lines.Click Open in your editor. Keep the right text, delete the marker lines (<<<<<<<, =======, >>>>>>>), save, then click Continue merge. Don’t assume your version (or the AI’s) should win; ask the person who wrote the other one.
Push was rejected: permission deniedYou may be signed into the wrong account, or you may not have write access.Check Accounts in Desktop settings. If you have no write access, ask the owner, or open a pull request instead.
Push was rejected: the online branch has newer commitsSomeone pushed since you last pulled.Click Fetch origin, then Pull origin, then push again.
Push was rejected: file too largeA very large file can be refused.Keep big datasets outside the repository.
I just committed something wrong, and haven’t pushedThe checkpoint is only on your computer.Click Undo below the commit box. Your edits come back to Changes. Only undo checkpoints you haven’t pushed. See step 16
A mistake is already pushed or mergedOther people may already have it.In History, right-click the commit and choose Revert changes in commit. Then click Push origin. Never force-push or delete shared branches to hide a mistake. See step 16
An unwanted edit I haven’t committedIt’s only in your folder.In Changes, click the file and read what would be lost. Copy anything you want to keep. Then right-click the file and choose Discard changes… This is hard to undo, so copy the folder first if unsure.

Three things people mix up

Commit ≠ Push. Commit saves on your computer. Push puts it online.

Fetch ≠ Pull. Fetch only checks for news. Pull brings it into your folder.

Pull request ≠ Merge. A pull request proposes. Merging accepts.
