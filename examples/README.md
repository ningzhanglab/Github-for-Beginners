# Example projects

These are **practice files only**. They are not real research, actual student projects, or verified economic findings.

## Main example: economics research

[Open the fictional economics project](economics/)

You can inspect a tiny invented county-year CSV, a research question, an initial results note, a data dictionary, and a checklist. It illustrates how a real GitHub **Issue #3** led to reviewed edits in **Pull Request #4**.

The GitHub records are real teaching demonstrations. The counties and measurements are fictional.

## Smaller example: reading notes

[Open the fictional reading-notes project](reading-notes/)

A simple plan and progress log show how a small documentation task can be tracked through **Issue #1** and **Pull Request #2**.

**Tip:** If you're practicing, create or copy these examples into *your own practice repository* before making changes. You don't need to edit this teaching repository.
