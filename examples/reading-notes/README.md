# Mini Research Project — Teaching Example

**This is a fictional project created solely for the GitHub Desktop beginner tutorial.** It contains no real participants, institutions, prices, or research findings.

## Project question

How should a two-person student team organize a short reading summary using GitHub Desktop and an AI agent?

## Project files

- [Research plan](research_plan.md): goals, timeline, and project responsibilities.
- [Progress log](progress_log.md): a short written record of work.
- A future *source-checking checklist* can be proposed on a separate branch, reviewed via a pull request, and merged.

## Roles

- **Alex (human project owner):** sets the task, verifies sources, reviews and merges proposed changes.
- **Sam (human collaborator):** reviews the clarity of the final summary.
- **AI assistant (illustrative contributor):** may prepare a draft or propose a PR on a branch when the authorized tools allow it.

These roles are fictional. Any GitHub issues and pull requests associated with this teaching example are demonstrations; they do not imply a real independent human collaborator or an autonomous agent reviewed the result.
