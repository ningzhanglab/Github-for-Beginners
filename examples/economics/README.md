# Mini Economics Research Project — Synthetic Data

**A fictional, beginner-friendly economics research example used to demonstrate GitHub Desktop.** All observations, county labels, and values are fabricated. Nothing here should be interpreted as an estimate of a real economic relationship.

## Research question

**How did unemployment rates and average hourly wages change between 2024 and 2025 across four fictional counties?**

This project demonstrates basic descriptive research, version history, collaboration, and reproducibility—not causal inference.

## GitHub teaching story

1. A researcher writes the question and commits a first draft.
2. An Issue identifies missing variable definitions.
3. An AI assistant *could* draft the documentation on a separate branch; in this demonstration ChatGPT prepared the edits using authorized GitHub tools.
4. The reviewer inspects the proposed files through [teaching PR #4](https://github.com/ningzhanglab/Github-for-Beginners/pull/4/files).
5. After merge, GitHub Desktop can pull the accepted version onto the researcher's computer.

**The repository actions here are real GitHub records; the research project, people, and dataset are fictional.** See the [lessons](../../lessons/README.md) (start with [Lesson 1](../../lessons/01-what-is-github.md)) for annotated steps.
