# 02 · Using GitHub Desktop

You can manage a project without learning any Git commands. This section is a visual guide to the **GitHub Desktop app** on Windows and Mac.

![Annotated drawing of GitHub Desktop's main areas](../assets/illustrations/desktop-controls-econ.svg)

*This is a simplified diagram, not an exact screenshot of the app.*

## Start with the buttons you'll use every day

| What I want to do | Where to look |
|---|---|
| Open a project from GitHub.com on my computer | **File → Clone Repository…** |
| Check what changed in my files | **Changes** |
| See older saved work | **History** |
| Save this set of changes | **Commit to [branch]** |
| Send my saved changes online | **Push origin** (or **Publish branch**) |
| Get changes made online | **Fetch origin**, then **Pull origin** if available |

Your files are edited in **an editor**, not in the GitHub Desktop app itself.
