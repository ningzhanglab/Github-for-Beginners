      Four rules that prevent most confusion

      Commit is not Push

      Commit saves a checkpoint on your computer. Push sends it to GitHub.com. Until you push, nobody else can see it.

      Fetch is not Pull

      Fetch checks whether GitHub.com has anything new. Pull actually brings those changes into your folder.

      Open is not merged

      A Pull Request is a proposal. Nothing changes in main until someone clicks Merge.

      "Done" is not proof

      When an AI says it finished, look for the actual files, branch or Pull Request before you trust it.
